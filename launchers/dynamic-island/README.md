# Dynamic Island launcher

Install **Dynamic Island** from RyoStore → App launchers, then select it in
Ryoku Settings → App Launcher. Super+Space opens search on the active monitor
with any bar style.

Type to search apps by name, description or keyword. Use the arrow keys or
Tab to select, Enter to launch, and Escape or a click outside to close.
Enter copies calculator results. Prefix a shell command with `>` to run
it, or use Ctrl+Enter to run it in a terminal.

The launcher opens as its own panel. If the Dynamic Island bar is installed,
give its `quickshell:islandLauncher` shortcut a separate key combination to
open search inside the bar.
